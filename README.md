# ProcessWatch

CSC501 solo project: Linux process monitoring using `/proc`, with planned eBPF execution-event monitoring.

## Status
Starter repository layout only. Implementation and build instructions will be added as features are developed.

## Planned modules
- `src/`: process discovery and security analysis
- `ebpf/`: eBPF program and user-space loader (subject to VCL support)
- `tests/`: test workloads
- `results/`: experimental measurements
- `docs/`: proposal, presentation, and final report
